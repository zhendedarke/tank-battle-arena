# Tank Battle Arena

A modern HTML5 tank battle game with smooth controls, enemy AI, power-ups, and dynamic gameplay.

![Tank Battle Screenshot](https://via.placeholder.com/800x400/0f2027/00eeff?text=Tank+Battle+Arena)

## Features

- **Smooth Controls**: Arrow keys to move, spacebar to shoot
- **Enemy AI**: Three types of enemy behaviors (wander, chase, patrol)
- **Power-ups**: Speed boost, shield, and multi-shot power-ups
- **Progressive Difficulty**: Game gets harder as you level up
- **Dynamic Gameplay**: Collision detection, health system, scoring
- **Modern UI**: Responsive design with game stats and controls
- **Multiple Difficulty Levels**: Easy, Medium, Hard, and Insane modes

## How to Play

1. Use **Arrow Keys** to move your tank
2. Press **Spacebar** to shoot bullets
3. Avoid enemy bullets and collisions
4. Destroy enemy tanks to earn points
5. Collect power-ups to gain temporary advantages
6. Survive as long as possible and achieve high scores!

## Power-ups

- **Speed Boost** ⚡: Increases tank movement speed
- **Shield** 🛡️: Temporarily protects from enemy bullets
- **Multi-shot** 🔫: Fires three bullets at once

## Game Elements

- **Player Tank**: Blue tank controlled by player
- **Enemy Tanks**: Red tanks with different AI behaviors
- **Walls**: Gray obstacles that block movement
- **Bullets**: Player (blue) and enemy (red) projectiles
- **Power-ups**: Glowing collectibles with special effects

## Installation & Running

Simply open `index.html` in any modern web browser. No additional dependencies or installation required.

### Local Development

If you want to modify the game:

1. Clone the repository
2. Open the files in your favorite code editor
3. Modify `game.js` for game logic, `style.css` for styling, or `index.html` for structure
4. Refresh the browser to see changes

## Technical Details

- Built with vanilla JavaScript (no frameworks)
- Uses HTML5 Canvas for rendering
- Object-oriented game architecture
- Collision detection using bounding boxes and circles
- RequestAnimationFrame for smooth animation
- Modular code structure for easy maintenance
